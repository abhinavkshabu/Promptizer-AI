What Promptizer Does

Promptizer AI is a Chrome extension that optimizes prompts for AI chatbots (ChatGPT, Google Gemini, Claude). When you click the Promptize button, your prompt text is processed to create an improved version and returned directly to you.

That's it. The extension has one job and doesn't do anything in the background beyond a lightweight server ping every 14 minutes to keep the cloud backend warm.

How Prompt Processing Works

When you click Promptize, your prompt text takes one of two paths:

Path 1 — On-device (Gemini Nano): If your Chrome has the built-in Gemini Nano model available, the optimization runs entirely on your machine. Your prompt never leaves your device.

Path 2 — Cloud (Groq via our server): Your prompt text is sent over HTTPS to our backend at promptizer-ai.onrender.com, which forwards it to the Groq API for processing. The optimized result is returned to you immediately. No prompt data is stored at any point in this chain.

Third-Party Services

Groq: When using the cloud backend, your prompt is processed by Groq's LLM API under their privacy policy: groq.com/privacy-policy

Chrome Built-in AI: On-device processing uses Google Chrome's Gemini Nano model. When this path is used, Promptizer has no involvement — no data is sent anywhere.

Render: Our backend is hosted on Render.com. Standard hosting infrastructure logs may apply per their terms.

Permissions Explained

Data Security

All network communication uses HTTPS encryption. No API keys or credentials are stored in the extension itself — they live exclusively on the server. We do not sell, share, or monetize any data in any form.
